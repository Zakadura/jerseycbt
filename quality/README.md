# M2 checks and release preparation

The local changes are based on published source `452064017b4dc4974cac7c675637cadb49d67578`. The original OneDrive checkout, GitHub settings and published site have not been changed. This branch is not a release instruction. Master still has the legacy ungated deploy workflow; direct writes to gh-pages are also possible. Do not merge application changes into Master before the separately approved workflow transition.

## Reproduce local checks

Use Node 24.20.0 (`.nvmrc`) and the committed lockfile. Run `npm ci`, `npx --no-install playwright install chromium firefox webkit`, then `npm run quality`. Tests start a loopback static server and stop it when finished. Missing browsers fail. Every generated HTML route is enumerated after the build; the placeholder draft must remain excluded. Journey tests run all three engines. The exhaustive axe/reflow suite runs Chromium, with all eight long-form templates also checked at enlarged text size. Keep `.quality`, `.lighthouseci` and browser profiles private and out of `dist`.

Performance uses direct Lighthouse 12.8.2 collection and Lighthouse CI 0.15.1 assertions on those exact reports. It never uses LHCI's older nested collector and never uploads to a public report service. Set CHROME_PATH to the locally installed Chrome matching M1 (152.0.7977.77). The Windows M1 profile records device/throttling, browser, blocked third parties and route medians. An incompatible browser/platform/profile fails comparison, even if absolute scores are good. The median must be >=90 and within five points of the reference; accessibility is 100, best practices/SEO >=95. M1 all four performance medians were 100. Chrome-launcher 1.2.1 is now a direct pinned dependency and its version is recorded in the summary; M1 already used 1.2.1, while the first M2 run inadvertently resolved the hoisted 0.13.4. Matched-browser reruns after this tooling correction must show the same environment and remain within the accepted score budget; the version correction alone does not authorize a baseline reset. Hardware and load variation still require human investigation.

Hosted CI is a different environment. It intentionally fails with an explicit missing-reference error until its own reviewed runner-specific baseline is supplied through PERFORMANCE_BASELINE. Do not copy M1 into a CI reference, suppress this check, or count that failure as the deliberately injected failure rehearsal. The prepared performance-reference.yml PR job collects a candidate even if absolute budgets fail, recording that outcome as advisory. It has no release marker. Public branch/PR authorization is still required before it can run. The authorized remote follow-up must first collect and review the hosted runner's three-run reference, record its provenance and decision, then configure BOTH rehearsal and final draft to that same file. Pin the runner/browser environment and resolve score instability before treating comparisons as evidence.

## Interactions and evidence limits

Synthetic Formspree fixtures cover accepted `{ok:true}`, field rejection `{errors:[{field,code,message}]}`, captcha/plan-style rejection, 5xx, invalid JSON, unknown 2xx, dropped network and timeout. Unknown or ambiguous receipt retains input and warns before a manual retry; no automatic duplicate sends. A genuine provider success is required to show acceptance. These fixtures prove local recovery, not this account's current API acceptance or delivery. M3 must verify both enhanced JSON and native action/method paths, allowed domains/captcha/plan settings and delivery to an owner-authorized test destination.

Calendly has one shared asset promise, explicit inline initialization, concurrent consumer tests, timeout/failure/retry and direct/email alternatives. The synthetic API records calls only; it does not certify the provider dialog's focus management, iframe availability or appointment completion. M3 owns real account and whole-journey checks without creating unauthorized bookings.

The sticky preference is a session-only dismissal; storage failure falls back to memory. Hidden controls are inert, the bar hides during field focus and on the booking route, and there is no required motion. Native details navigation and direct booking links work without JavaScript. Shared English content on Portuguese pages is marked; Portuguese links and sticky labels use pt. Clinical facts, prices and content claims are unchanged pending the owner's M3 review.
